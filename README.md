# 赤骸夜行 · CRIMSON HUSK NIGHTWALK（战斗原型）

浏览器里直接玩的 3D 第三人称动作战斗原型。灵感来自“都市夜色 + 体内长出的武器”这类主题，**所有角色、组织、能力名称都是原创**。
技术：Three.js r170（已内置在 `vendor/`，离线可跑，无需构建），原生 ES Module。

在线试玩：https://menghao11.github.io/ghoul-action/

## 运行

```bash
# 在仓库根目录起任意静态服务器，例如：
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
# 强制触屏界面：?touch=1   指定画质：?q=high|mid|low   跳过开始面板：?autostart=1
```

### 连招与系统
- **轻 ×4**：连斩（四种血绫各自不同的四段）。
- **轻 → 轻 → 重**：升绫（挑空）。挑空后按 **跳跃** 会自动朝浮空目标追击跳 → **空中轻 ×3**（空绫，敌我都会滞空）→ **空中重**：坠星（下砸落地冲击波，可把浮空敌人砸地反弹）。
- **闪避后 0.45 秒内攻击**：闪反（突进重刺）。
- **敌人出手前一瞬闪避（闪避开始 0.26 秒内被判定）**：瞬影 → 子弹时间（敌人 0.2 倍速，画面红色暗角 + 闪光环），子弹时间内攻击 = 瞬影反击（闪到敌人身后三连斩，最后一击挑空）。
- **磐盾格挡**：按住技能。敌人命中前 0.22 秒内举盾 = 完美格挡（敌人硬直、Boss 削韧）；格挡中按攻击 = 反震。
- **输入缓冲 0.3 秒**；每招都有取消窗口：出手后任何时候可用闪避取消，cancel 点之后可接任意招/跳跃；切换血绫随时可用。
- **打击感**：顿帧（hit-stop，按招式轻重 25–300ms）、红色残影、血雾粒子 + 火花、伤害数字、冲击环、命中闪红。**全程没有任何屏幕/镜头晃动**（无位置/旋转抖动、无 FOV 冲击），有自动化检查守着。
- **能量**：命中、完美闪避、完美格挡积累。满后 **绯魇**：15 秒，全身长出尖刺甲壳 + 6 条缠身血绫，伤害 ×1.6、受伤 ×0.45、移动更快、每招都带残影；绯魇中再按一次释放终结技 **绯魇·终焉**（升空、血绫刺穿 14 米内所有敌人，6 段伤害，最后一击大顿帧 + 子弹时间）。

## 关卡流程
1. 波次 1：3 名骨刃。2. 波次 2：2 名骨刃 + 1 名铁枷（霸体，轻伤不打断，慢速大预警砸地）+ 2 名晶刺手（地面红线预警后投射晶刺）。3. Boss 铁衡（2600 HP，韧性 700，破防 2 秒；无敌 bot 约 25–31 秒）：
   - 第一阶段：三连横扫（扇形预警）、直线冲锋（长条预警）。
   - 第二阶段（65%）：咆哮推开 + 召唤 2 名骨刃（一击跨过两档也会逐级进入，不跳过召唤）；新增跃起砸地（落点圆形预警，会追踪到最后 0.45 秒）、五连扇形弩箭。
   - 第三阶段（30%）：出招更快，新增回旋斩（大圆预警，3 段）。
   - 所有敌人攻击都有地面预警圈（填充到边缘 = 出手），武器同时变红发光。

## 创意加料（第二轮）
全部服务打击感，**没有晃屏、没有频闪**（亮度变化都是平滑过渡）。
- **子弹时间雨滴悬停**：完美闪避/顿帧时雨丝几乎停在空中，并略微变亮。
- **连击评价 凡→神（C/B/A/S/SS/SSS）**：变招、空中命中、完美闪避/格挡加分，挨打掉段，停手平滑衰减。评价越高血绫拖尾和辉光越亮，S 以上每招都带残影。HUD 只做一次柔和的缩放入场。
- **四种终焉变体**：陨星雨（晶刺从天而降）、崩天（同心冲击环 + 地面血晶）、血潮（每段爆血并回血）、龙卷（身体旋转、螺旋冲击）；横幅显示变体名。
- **血晶花**：终焉最后一击和 Boss 倒下处绽放发光的血晶簇，几秒后缓慢收拢消失。
- **处决碎面具**：敌人死亡时面具碎片飞散、落地、淡出（模型版按面具颜色：瓷白骷髅/红鸦喙/铁枷）。
- **霓虹短路**：重击、砸地、终焉的冲击波让附近招牌暗下、落下火花、再缓慢复燃（不闪烁）。
- **处决推进镜头**：放「终焉」时镜头沿视线平滑推近约 32%（缓入 0.45s → 保持 → 缓出 0.8s），只改距离，FOV 不变；每段单调，零振荡。
- **刺穿慢放**：游龙 突刺（第 3 段轻击）和 贯龙（重击）命中时，敌方时间降到 0.3 倍约 0.3 秒，同时镜头轻推近；0.6 秒冷却，不弹横幅、不闪屏。
- **绯魇调色**：全屏后期 pass（Bloom 之后），红色保留，其它颜色去饱和并偏向红黑，暗部柔和下压；约 0.6s 渐入、1s 渐出，无频闪。低画质也生效（仅在调色时启用后期链）。
- **配乐节拍辉光**：血绫辉光随音乐拍点做很小的余弦起伏（`world.music.musicBeatPhase`）。

## 主角观感与移动修正（第三轮）
- **角色着色**（`art/lib/toon3d_loader.js` 的 `enhanceToon`）：5 级色阶、暗部抬升（深色布料不再糊进夜景）、菲涅尔边缘光、卡通高光带。主角冷色边缘光、敌人暗红、Boss 暖白，敌我一眼可分。纯着色，不加灯、不加 draw call。
- **主角体型**（`src/herofix.js` 的 `reshapeHero`）：加载时沿各骨骼做径向放大（按蒙皮权重混合），大腿/小腿/手臂加粗、躯干加厚、胯部加宽。不改 GLB 文件。
- **主角动作**（`buildHeroClips`）：idle / run / jog / jump 用两骨 IK 程序生成，替换 GLB 里的同名 clip。跑步着地期间脚踝相对身体恒速后移，循环时长按「着地位移 = 速度 × 着地时间」反推（`GAITS.run.speed` = 7.2 m/s），播放速度 = 实际速度 / 设计速度，着地脚滑动从约 8 cm/帧降到 0。摇杆轻推时用 jog（约 3.2 m/s），切换保持相位。
- **转向压弯**：跑动中按转向角速度向弯内侧倾身（最大约 11°，平滑过渡）。
- 对比原版：`?herofix=0`（体型和动作退回 GLB 原样）。

## 3D 角色（画图王）
- `art/models/`：凌夜 `lingye.glb`（触屏/中低画质用 `lingye_1k.glb`）、铁衡 `tieheng.glb`（缩放 1.32 ≈ 2.8 m，猎械「鸦断」挂 `hand_R_socket`）、骨刃 `foe_melee.glb`（+锯齿砍刀）、晶刺 `foe_ranged.glb`、铁枷 `foe_brute.glb`。用 `art/lib/toon3d_loader.js` 的卡通材质 + 蒙皮描边，`SkeletonUtils.clone` 实例化（共享几何/贴图）。
- 动画原地播放、位移由代码驱动；按招式第一次出手时间缩放 clip（如 light1 出手帧 0.14 s 对齐判定帧），状态间 0.05–0.25 s 交叉淡化。血绫从 `tendril_root` 长出。蒙皮残影用“冻结骨架”快照。
- 已知美术问题的处理：铁衡 `sweep` 第一段刀身竖着 → 该 clip 期间把武器绕刀身轴转 90°。
- `art/fx/`：血绫管体条带（albedo + emissive）、冲击环、命中火花序列帧、四芒星闪（完美闪避/重击/终焉）、月牙斩（近战出手）、赫眼光晕（绯魇/完美闪避）。
- 加载失败或 `?models=0` 时自动退回程序化占位模型。手机：Boss 2048² 贴图在加载时降到 1024²。

## 配乐（声音王）
- `audio/MANIFEST.md` + OGG/M4A（Safari 用 M4A，其它按 `canPlayType`）。Web Audio `AudioBufferSourceNode` 循环，`loopEnd = 母带采样数 / 44100` 显式设置（M4A 尾部补零不影响）。
- 按局势交叉淡入淡出：探索 → 战斗 → Boss → 三阶段 → 胜利短曲（一次性）。Boss a→b：取 a 当前位置向上取整到下一小节线（1.6 s），b 从同一偏移开始，0.4 s 交叉。
- 战败：不再播探索曲，当前曲目低通后 2.8 秒淡出到静音。
- 绯魇叠加层：杂兵战用 `layer_feiyan`（战斗曲小节线进入），Boss 战用 `layer_feiyan_boss`（Boss 曲小节线进入）。子弹时间时音乐整体低通。
- 首次手势解锁 AudioContext（iOS）；操作面板里有音乐/音效音量滑杆（保存在 localStorage）；没有 audio/ 时静默降级为只有音效。

## 发布到 GitHub Pages
- 发布方式：**GitHub Actions**（`.github/workflows/pages.yml`）。每次推送到 `main`，工作流运行 `node tools/build_dist.mjs dist`，只把运行时文件上传部署：`index.html`、`style.css`、`.nojekyll`、`src/`、`vendor/`、`art/lib/`、`art/manifest.json`、游戏用到的 `art/models/*.glb`、`art/fx/*.png`、`audio/MANIFEST.md` 和 `audio/*.ogg|m4a`（约 17 MB）。`tests/`、`tools/`、`shots/`、README、美术/音频源文件不会发布。
- **首次切换**：仓库 Settings → Pages → Build and deployment → Source 改成 **GitHub Actions**（原来是 “Deploy from a branch”）。
- 本地预览发布内容：`node tools/build_dist.mjs`，然后在 `dist/` 里起静态服务器；`dist/` 不入库。
- 全部相对路径，可放在子路径（`/ghoul-action/`）下；不依赖目录列表。构建时自动跑 `tools/stamp.mjs` 给 `style.css`、`src/main.js` 和 import map 里每个 `src/*.js` 加 `?v=<内容哈希>`（改代码后提交前也可以手动跑一次，让仓库里的 index.html 同步）。
- 运行时清单是 `art/manifest.json`（只列游戏用到的贴图）。测试会把 `git archive HEAD` 的干净导出、以及由它构建的 `dist/` 分别挂在 `/ghoul-action/` 子路径下运行，要求零 404、零控制台错误。

## 架构

```
index.html / style.css     HUD、触屏按钮、操作说明（中文）
vendor/                    three.module.js r170 + 用到的 addons（后处理、BufferGeometryUtils），MIT
src/main.js                World：渲染器/后处理(Bloom)、主循环、时间缩放（顿帧/子弹时间）、战斗结算、投射物、波次、__dbg 调试钩子
src/player.js              主角状态机（move/attack/dodge/guard/hurt/ult）、输入缓冲与取消窗口、目标吸附/突进、程序化动画、血绫驱动、绯魇
src/moves.js               招式数据表（时间轴、判定、突进、血绫动作、投射物、吸血）
src/tendril.js             血绫：弹簧-阻尼链（120Hz 子步）+ 平行移动标架的管状网格（顶点原地更新、零 GC）+ 尖端拖尾
src/enemy.js               骨刃/晶刺/铁枷/Boss AI、预警-出手-收招、浮空/倒地/硬直、韧性与阶段
src/rig.js                 低多边形分层关节人形 + 姿势库 + 平滑姿势混合
src/camera.js              第三人称轨道 + 锁定：一阶预滤波 + 临界阻尼 SmoothDamp，限速转向，防穿楼；固定 FOV，无任何抖动代码
src/fx.js                  血雾/火花粒子池、残影、地面预警贴花、冲击环
src/city.js                程序化夜街：合并楼体、窗户贴图、霓虹招牌（Canvas 文字）、路灯光池、湿路面假反射、灯笼、雨丝
src/hud.js / audio.js      DOM HUD（伤害数字、锁定标记、Boss 条）/ WebAudio 合成音效（iOS 首次触摸解锁）
src/input.js               动作层输入：键盘、鼠标（Pointer Lock）、多点触控摇杆/视角/按钮
src/creative.js            连击评价、碎面具、血晶花、终焉变体
src/models.js / artfx.js   3D 角色接入（克隆、clip 驱动、预算统计）/ 画图王 fx 贴图特效
src/grade.js               绯魇调色后期 pass
src/music.js               配乐管理（清单解析、交叉淡化、小节线切换、绯魇层、音量）
tools/stamp.mjs            缓存版本号
tools/build_dist.mjs       生成只含运行时文件的 dist/（Pages 发布用）
.github/workflows/pages.yml  GitHub Actions：构建 dist/ 并部署到 Pages
tests/smoke.js             Playwright 自动化测试（见下）
tests/boss_ttk.js          Boss 击杀时长基准
tests/gallery.js           截图集
```

时间：顿帧把模拟时间缩到 0.04 倍（相机仍按真实时间平滑跟随，所以画面不会“卡”也不会“抖”）；子弹时间让敌人 0.2 倍速、主角 0.8 倍速。

## 已知不足 / 下一步
- headless 浏览器用 SwiftShader 软件渲染，FPS 数字只能参考；**60fps 需要在真 iPhone Safari 和桌面实测**（画质「低」关闭 Bloom/抗锯齿/雨丝，DPR=1）。
- 3D 角色是程序化建模 + 程序关键帧动画（没有动捕）；风衣下摆有轻微穿插（未处理）。占位模型仍保留作后备。
- 配乐还没有在真机上试听过；没有手柄支持、没有按键改绑。
