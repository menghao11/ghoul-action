# 赤骸夜行 · CRIMSON HUSK NIGHTWALK（战斗原型）

浏览器里直接玩的 3D 第三人称动作战斗原型。灵感来自“都市夜色 + 体内长出的武器”这类主题，**所有角色、组织、能力名称都是原创**。
技术：Three.js r170（已内置在 `vendor/`，离线可跑，无需构建），原生 ES Module。

> 本仓库只在本地提交，**没有推送、没有发布**。

### 连招与系统
- **轻 ×4**：连斩（四种血绫各自不同的四段）。
- **轻 → 轻 → 重**：升绫（挑空）。挑空后按 **跳跃** 会自动朝浮空目标追击跳 → **空中轻 ×3**（空绫，敌我都会滞空）→ **空中重**：坠星（下砸落地冲击波，可把浮空敌人砸地反弹）。
- **闪避后 0.45 秒内攻击**：闪反（突进重刺）。
- **敌人出手前一瞬闪避（闪避开始 0.26 秒内被判定）**：瞬影 → 子弹时间（敌人 0.2 倍速，画面红色暗角 + 闪光环），子弹时间内攻击 = 瞬影反击（闪到敌人身后三连斩，最后一击挑空）。
- **磐盾格挡**：按住技能。敌人命中前 0.22 秒内举盾 = 完美格挡（敌人硬直、Boss 削韧）；格挡中按攻击 = 反震。
- **输入缓冲 0.3 秒**；每招都有取消窗口：出手后任何时候可用闪避取消，cancel 点之后可接任意招/跳跃；切换血绫随时可用。
- **打击感**：顿帧（hit-stop，按招式轻重 25–300ms）、红色残影、血雾粒子 + 火花、伤害数字、冲击环、命中闪红。**全程没有任何屏幕/镜头晃动**（无位置/旋转抖动、无 FOV 冲击），有自动化检查守着。
- **能量**：命中、完美闪避、完美格挡积累。满后 **绯魇**：15 秒，全身长出尖刺甲壳 + 6 条缠身血绫，伤害 ×1.6、受伤 ×0.45、移动更快、每招都带残影；绯魇中再按一次释放终结技 **绯魇·终焉**（升空、血绫刺穿 14 米内所有敌人，6 段伤害，最后一击大顿帧 + 子弹时间）。

## 关卡流程
1. 波次 1：3 名巡夜员。2. 波次 2：3 名巡夜员 + 2 名弩手（地面红线预警后射击）。3. Boss 铁衡（4000 HP，韧性条，破防 2 秒）：
   - 第一阶段：三连横扫（扇形预警）、直线冲锋（长条预警）。
   - 第二阶段（65%）：咆哮推开 + 召唤 2 名巡夜员；新增跃起砸地（落点圆形预警，会追踪到最后 0.45 秒）、五连扇形弩箭。
   - 第三阶段（30%）：出招更快，新增回旋斩（大圆预警，3 段）。
   - 所有敌人攻击都有地面预警圈（填充到边缘 = 出手），武器同时变红发光。

## 架构

```
index.html / style.css     HUD、触屏按钮、操作说明（中文）
vendor/                    three.module.js r170 + 用到的 addons（后处理、BufferGeometryUtils），MIT
src/main.js                World：渲染器/后处理(Bloom)、主循环、时间缩放（顿帧/子弹时间）、战斗结算、投射物、波次、__dbg 调试钩子
src/player.js              主角状态机（move/attack/dodge/guard/hurt/ult）、输入缓冲与取消窗口、目标吸附/突进、程序化动画、血绫驱动、绯魇
src/moves.js               招式数据表（时间轴、判定、突进、血绫动作、投射物、吸血）
src/tendril.js             血绫：弹簧-阻尼链（120Hz 子步）+ 平行移动标架的管状网格（顶点原地更新、零 GC）+ 尖端拖尾
src/enemy.js               巡夜员/弩手/Boss AI、预警-出手-收招、浮空/倒地/硬直、韧性与阶段
src/rig.js                 低多边形分层关节人形 + 姿势库 + 平滑姿势混合
src/camera.js              第三人称轨道 + 锁定：一阶预滤波 + 临界阻尼 SmoothDamp，限速转向，防穿楼；固定 FOV，无任何抖动代码
src/fx.js                  血雾/火花粒子池、残影、地面预警贴花、冲击环
src/city.js                程序化夜街：合并楼体、窗户贴图、霓虹招牌（Canvas 文字）、路灯光池、湿路面假反射、灯笼、雨丝
src/hud.js / audio.js      DOM HUD（伤害数字、锁定标记、Boss 条）/ WebAudio 合成音效（iOS 首次触摸解锁）
src/input.js               动作层输入：键盘、鼠标（Pointer Lock）、多点触控摇杆/视角/按钮
tests/smoke.js             Playwright 自动化测试（见下）
tests/gallery.js           截图集
```

时间：顿帧把模拟时间缩到 0.04 倍（相机仍按真实时间平滑跟随，所以画面不会“卡”也不会“抖”）；子弹时间让敌人 0.2 倍速、主角 0.8 倍速。

## 已知不足 / 下一步
- headless 浏览器用 SwiftShader 软件渲染，FPS 数字只能参考；**60fps 需要在真 iPhone Safari 和桌面实测**（画质「低」关闭 Bloom/抗锯齿/雨丝，DPR=1）。
- 角色是分层关节的低多边形占位模型，没有骨骼蒙皮和手 K 动画；没有真正的布料/头发。
- 无音乐，只有合成音效；没有手柄支持、没有按键改绑。
- 相机防穿楼只按街道边界做了简化（街区是直街，够用）；楼顶/室内不可进入。
- Boss 只有一个；没有存档、成长、剧情；死亡/通关后整页重开。
- 平衡只做了粗调（全流程自动 bot 在 god 模式约 1 分钟通关）。
